# 架构

[English](Architecture) · **中文**

代码为什么这样组织。如果你打算读或改它，这页有用；只用库的话可以跳过。

## 包的划分

```
github.com/xiaoLangZe/go-muyuan/          package muyuan —— 公开 API
├── muyuan.go      管理器：选项、AddTask、调度器
├── task.go        任务：句柄，暂停/继续/重下/删除
├── events.go      事件流
├── options.go     任务级选项
├── status.go      Status / Progress / Info / RangeMode
├── errors.go      错误哨兵
└── internal/
    ├── engine/    传输引擎：一个文件的生命周期
    ├── hostguard/ 拦回环、私网与保留地址
    └── filename/  文件名推导与净化
```

公开包放在模块根目录，所以导入路径就是模块路径：`import "github.com/xiaoLangZe/go-muyuan"`。包名是 `muyuan`，比 `go_muyuan` 短、且是合法 Go —— 包名不能含连字符。

`internal/` 无法从模块外导入，所以 `engine`、`hostguard`、`filename` 都是实现细节。它们里面的东西不是公开 API，任何版本都可能变。

## 两个所有者

- **引擎**负责一个文件的传输：状态机、这个文件的连接额度、分片、部分文件、重试与停滞。它不知道别的文件存在。
- **管理器**负责连接池和文件运行的次序。它通过调引擎来给每个任务分配连接数，从不碰传输本身。

这个划分就是引擎上存在 `SetWorkers` 的原因：它是调度器唯一要拧的旋钮。调度器每次变更都从头重算全部并应用结果，这让[调度的两条规则](Scheduling-and-Budget-zh)集中在一处，而不是散落在触发它们的各个操作里。

## 为什么有两条传输路径

引擎有一条单连接路径和一条并行路径。两者下同一个文件、共用同一套生命周期，但它们是**实实在在不同的算法**，简单的那条并不是复杂那条的子集：

| | 单连接 | 并行 |
| --- | --- | --- |
| 请求 | 一次；只有续传时带 `Range` | 每片一次，各自带明确区间 |
| 部分文件 | 随字节到达增长 | 创建成完整大小，原地写入 |
| 完成度由什么记录 | 文件长度 | 64 KiB 位图 |
| 续传需要 | 一个偏移量 | 位图 |

以下情况用单连接：文件只分到 1 条连接、服务端不支持 Range、大小未知、或文件太小不值得切。给单连接预分配整个文件、维护位图，纯粹是开销，所以两条路径是分开的，而不是硬凑成一条。

## 为什么用位图而不是固定分片

把文件预切成 N 个固定分片会在开头就把分片边界和连接数都定死。而这些恰恰必须保持灵活：

- 调度器会在文件运行期间改变它的连接数；
- 切片长度会随实测吞吐调整。

所以完成度用 64 KiB 分辨率的位图记录，而「一片」就是某个 worker 当时认领到的一段空闲粒度。这样一来，改切片长度和改 worker 数都变得微不足道：位图不关心。

位图也是暂停时不需要任何补偿计算的原因。在途的一片就是没被标记完成，所以之后重取；没有任何中间状态需要调和。

## 并发模型

引擎内部，`ctl` 串行化生命周期操作 —— start、pause、restart、delete —— 每个都全程持有它，包括等待上一轮返回。而传输本身只取 `mu`，这正是让那个等待不会死锁的原因。同一时刻只有一个传输在跑。

管理器内部，调度器是一个单协程，被任何变更唤醒时重算分配。对引擎的调用在管理器的锁之外进行，因为其中一些会阻塞。

## 两层之间的类型别名

`Status`、`Progress`、`Info`、`RangeMode`、`Option` 都是引擎类型的别名：

```go
type Status = engine.Status
type Option = engine.Option
```

所以从任务读到的值，和引擎深处读到的值，是同一个类型，而不是两份靠人工同步的定义。错误同理：公开的哨兵值**就是**引擎的哨兵值，这也是 `errors.Is` 能跨层工作的原因。

## 几个值得知道的设计决定

- **主机校验接在 dialer 上**，不只是在请求前检查一次，所以并行路径无法绕过它。
- **事件发射协程是懒启动的**，首次调用 `Events()` 才起，所以没人观察的任务不占协程。
- **部分文件只会被改名**，绝不会以最终文件名写入，所以中断的下载不可能留下看起来完整的东西。
- **模块内零第三方依赖**。
